Key Provisions｜主要條款

  • 不扣基本薪資：所有事故均不涉及基本工資扣減 No wage deduction: base salary is not affected by any incident
  • 績效導向：自有員工影響年終安全係數；勞務人員影響供應商 KPI Performance-based: incidents affect year-end bonus (direct) or agency KPI (staffing)
  • 遞進式處分：依嚴重程度與次數分級，所有違規均留存紀錄 Progressive discipline: tiered by severity and frequency; all violations documented
  • 必須留檔：所有事故完成 Incident Report 並存入 ADP 員工檔案 Documentation required: all incidents require a completed Incident Report on file
